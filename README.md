# Benjamin Ward Portfolio

The source for [benjamin-ward.com](https://benjamin-ward.com), a one-page
portfolio highlighting Benjamin Ward's technology leadership, security work,
community service, education, and certifications.

## Prerequisites

- Node.js 22 or newer

## Quick Start

```bash
npm install
npm run dev
npm run build
```

The production build is a static export written to `out/`. Netlify uses the
settings in `netlify.toml` to build and publish that directory.

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: create the production export
- `npm test`: build and verify the rendered portfolio
- `npm run lint`: check the source code
